## Defect and fix

`duplicateSelectedFeatures()` intentionally selected the new clone indexes, but
`commitLayerFeatureChanges()` refreshed the active project through
`setActiveProject()`, which unconditionally discarded that selection. The refresh
also retained `activeSurveyAnnotation`, so the previous annotation's editable
Feature Details remained visible after its map object had been rebuilt.

The project refresh now has an explicit `preserveSelection` contract. Layer
mutation commits use it, while ordinary project switches still clear selection.
Every refresh clears the soon-to-be-stale active annotation and closes Feature
Details. This covers duplicate, merge, simplify, densify, styling, and other
layer mutation journeys that share the commit path.

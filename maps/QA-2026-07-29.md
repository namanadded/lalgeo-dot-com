## Defect and fix

Reproduction on production:

1. Create a browser-only project with a polygon layer.
2. Start Add New and place fewer than three vertices.
3. Press Escape (the visible Cancel drawing button had the same incomplete path).
4. Drawing exits, but the “more vertices needed” coach remains and the status says “Point placement cancelled.”

The fix adds `cancelActiveFeaturePlacement()` as the shared Escape/toolbar recovery path. It captures the active geometry and trace state before clearing transient drawing state, hides the workspace coach, and announces point placement, line/polygon drawing, or trace cancellation accurately. The keyboard help now describes all feature drawing.

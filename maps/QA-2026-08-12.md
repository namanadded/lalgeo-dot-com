## Defect and fix

Production advertised platform-aware keyboard shortcuts for New Layer, Import Layer, Share, Export, Export Map/PDF, Print, Recent Projects, and My Location, but the document-level keyboard handler did not implement those commands. This made the keyboard path disagree with the visible menu contract.

The fix adds a shared keyboard-command dispatcher that invokes the same button journeys as pointer input, reports existing disabled-prerequisite explanations instead of failing silently, implements the complete missing shortcut set, and preserves field safety for the unmodified `M` location command. A new regression synchronizes advertised labels, handlers, target controls, print/PDF precedence, disabled recovery, and Production CI inclusion.

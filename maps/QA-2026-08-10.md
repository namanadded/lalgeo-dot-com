## Coverage gap and change

Production was healthy, but six existing core regression scripts were not required by `Production CI`: desktop project header, desktop drawing, mobile tool experience, mobile sheet refinement, toolbar interaction state, and large API point performance. A green local run could therefore hide a regression in those journeys.

All six are now explicit CI requirements. A new meta-regression compares every `test:*` package script with the workflow, fails on missing, duplicate, or unknown commands, and establishes the complete 74-test inventory as a durable contract. This prevents future journey coverage from silently becoming orphaned.

## Fix and regression coverage

The New Layer journey now supplies stable accessible names and associated help for both fields, exposes required/invalid/status semantics, explains the point/line/polygon choice, and supports Enter-to-create without bypassing validation or interfering with IME composition.

The shared layer-action dialog now explicitly prioritizes `[autofocus]` before falling back to the first control. This repairs the root focus-order defect for New Layer and every other dialog that declares an intended initial field. Focus trapping, Escape handling, and return focus remain intact.

`test-new-layer-dialog-journey.mjs` covers accessible names and descriptions, synchronized validation, guarded Enter submission, autofocus priority, focus trapping, and return focus. Production CI now requires it.
